# React Fullstack: Проектная работа 11-го спринта

> **Проект** — интерактивное SPA-сервис со сложной авторизацией, управлением пользователями и защищёнными маршрутами.

---

## Описание проекта

Данный проект является финальной работой 11-го спринта, предусматривает реализацию современного React-приложения с использованием Redux Toolkit, продвинутой маршрутизацией, полной системой авторизации и управления профилем пользователя. Основное внимание уделяется типизации, тестированию и безопасности.

## Технологии и стек

- **Create React App** — быстрый старт и удобная конфигурация сборки
- **Redux Toolkit** — лаконичные и эффективные инструменты для глобального состояния
- **React Router** — современная маршрутизация, полная поддержка вложенных маршрутов и редиректов
- **TypeScript** — строгая типизация компонентов, страниц, редьюсеров и утилит для снижения числа ошибок на этапе разработки
- **Авторизация и аутентификация**
  - Регистрация, вход, восстановление и сброс пароля, редактирование профиля пользователя
  - **Cookies** — хранение access и refresh токенов для надёжной аутентификации пользователя
  - **Защищённые маршруты** — ограничение доступа к разделам приложения без авторизации
- **Тестирование**
  - **Тесты редьюсеров** — unit-тесты бизнес-логики
  - **Функциональные тесты** с использованием **Cypress** — проверки пользовательских сценариев
- **Адаптивная верстка** — полное соответствие макету и корректное отображение на всех распространённых устройствах и разрешениях

---

## Функционал

- Регистрация и аутентификация пользователя
- Восстановление и сброс пароля по email
- Просмотр и редактирование профиля (личные данные, почта, пароль)
- Безопасное хранение токенов в cookie
- Ограничение доступа к приватным страницам для неавторизованных пользователей
- Удобная навигация по приложению
- Корректное отображение ошибок (валидация, авторизация, сетевые сбои)
- Интуитивно понятный интерфейс, соответствующий макету
- Высокое покрытие тестами бизнес-логики

## Установка и запуск проекта

### 1. Клонируйте репозиторий

```bash
git clone <адрес-репозитория>
cd <название-папки>
```

### 2. Установите зависимости

```bash
npm install
```

_или_

```bash
yarn install
```

### 3. Запустите проект

```bash
npm start
```

или

```bash
yarn start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

---

## Скрипты

- `npm start` — запуск dev-сервера
- `npm run build` — сборка проекта для продакшена
- `npm run test` — запуск unit-тестов (редьюсеры и бизнес-логика)
- `npm run cypress` — запуск Cypress для функциональных e2e-тестов

## Структура проекта

```
src/
 ├── components/       # общий переиспользуемый UI
 ├── features/         # slice-редьюсеры, логика и асинхронные thunk-и
 ├── pages/            # страницы приложения/маршруты
 ├── hooks/            # кастомные хуки
 ├── utils/            # вспомогательные утилиты, проверки
 ├── api/              # описание взаимодействия с сервером
 ├── types/            # глобальные типы и интерфейсы (TypeScript)
 └── ...
```

## Дополнительная информация

- Все чувствительные данные (токены) хранятся только в cookie при помощи безопасных опций.
- Реализована обработка возможных ошибок с информированием пользователя.
- Для приватных маршрутов используется защищённый HOC (`ProtectedRoute`).
- Для тестирования полностью покрыты редьюсеры и ключевые действия Cypress-сценариями.
- Адаптивный и доступный дизайн по макету Figma.
